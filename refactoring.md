# Refactoring

## Equations of State

Необходимо привести EoS к опрятному виду. У каждого уравнения состояния
должны быть следующие функции:

- `energy`
- `entropy`
- `stress`
- `acoustic`
- `temperature`

Они должны иметь одинаковые аргументы. Для повторяющихся функций вроде
`stress` нужно реализовать функции под каждую меру деформации:

- `stress_finger`
- `stress_grdef`
- ...

Обычные же функции `stress` являются обертками для них.

Также нужно объединить файлы уравнений состояния для одной и двух фаз.

## HLL/HLLEM

Необходимо разделить все функции численных потоков и доработать HLLEM (итерации).
